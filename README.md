# SoftGrowTech_InteractiveFormValidation

Task 1 — Project 2: Interactive Form Validation
Internship: Frontend Development | SoftGrowTech

## Overview
A registration form that validates every field in real time using plain
JavaScript — no libraries. Built to satisfy the Task 1 brief and extended
with a few extra touches for polish and usability.

## Tools Used
- HTML5
- CSS3
- JavaScript (Vanilla, ES6)

## Folder Structure
InteractiveFormValidation/
├── css/
│   └── style.css
├── js/
│   └── script.js
├── index.html
└── README.md
## Features (per task requirements)
- Real-time validation as the user types
- Clear inline error/success messages per field
- Submit button stays disabled until the whole form is valid

## Extra features (added beyond the brief)
- Floating labels for a cleaner, modern input style
- Password strength meter (weak / fair / good / strong)
- Confirm-password live match check
- Username field with a debounced "availability" check
- Date of birth field with automatic age validation (13+)
- Required terms & privacy checkbox before submission
- Pakistani phone number format validation (03XXXXXXXXX)
- Success banner on submit, auto-clears the form after 4 seconds

## How to Run
Open `index.html` directly in a browser, or serve the folder with
any static server (e.g. VS Code Live Server extension).
